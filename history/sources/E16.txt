CONTEXT

F is a finite union-closed family of distinct sets containing empty. q_F(A)
counts ORDERED pairs (B,C) with B union C=A, including equal pairs. The original
candidate says that every target maximizing q_F contains an abundant coordinate
(one belonging to at least half of F). We have not proved this in general.

For a fixed modal A, its exact internal core is G={B in F:B subset A}.
For each nonempty occurring exterior trace Z, put
 H_Z={B intersect A:B in F, B minus A=Z}.
Each H contains A, is G-stable (g union h in H), is union-closed, and obeys
 C_G(H):=2Q_A(G,H)+Q_A(H,H) <= q:=Q_A(G,G),                    (1)
where Q_A counts ordered cross pairs whose union is A. This is a necessary
condition from q_F(A union Z)>=C_G(H) and q_F(A)=q.

Nonnegative coordinate weights p, total W, define
 S_p(H)=sum_{T in H}(2 sum_{i in T}p_i-W).
If S_p(G)>=0 and S_p(H)>=0 for all permissible fibres, summing proves abundance
inside the positive weight support. The four certified cores here have strictly
positive core surplus, so they give strict abundance in every extension with
that exact core and a modal target. This was already known from prior complete
fibre enumeration; the new work is a different, stronger relaxed certificate.

The ordinary graph test keeps unary G-stability and excludes individually
over-budget traces. It drops binary closure and the full nonlinear bound (1).
For T in H, its principal image I_T={g union T:g in G} is contained in H.
If C_G(I_T)>q, T is forbidden. If C_G(I_T)=q, H must equal I_T whenever it contains
T, since adding a trace strictly increases cost. The saturated-image split
checks those exact images separately and excludes saturated traces from the
remaining graph problem. These necessary restrictions can still be too weak.

JOINT TRACE RULE

If T,U both belong to H, G-stability forces I_T union I_U subset H. Therefore
                   C_G(I_T union I_U)>q                     (2)
implies that T and U cannot coexist. Each image can be strictly under budget
on its own. No binary-union closure of I_T union I_U is used: this is a pure
joint-cost exclusion, valid even for the relaxed unary-closed family class.

For a negative source-side family from the graph, select a violating pair
using the largest joint cost, with deterministic trace-order tie breaks.
Branch into two subproblems: exclude T, or exclude U. Every remaining valid
fibre belongs to at least one branch. The branches may overlap; disjointness is
unnecessary for a cover proof. Each positive leaf exports an integer flow and a
matching cut. Together they prove the exact graph minimum is nonnegative.
This certifies a class larger than the actual union-closed fibres.

At a negative leaf with no violating pair, the pair method remains unresolved
unless that leaf is independently an actual permissible negative witness. A
node-limit stop is also unresolved. Neither is an absence proof. Pairwise tests
can miss higher-order cost conflicts, and branching can grow exponentially.

being counted as completed proofs. It does not call the optimizer to establish
the exported certificates' optimality. All four proofs passed.

size theorem, obstruction to the candidate, or historical priority is claimed.
